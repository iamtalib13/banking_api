Value Dated TTUM

Upload Excel file and convert it into Value Dated TTUM TXT files.

Excel header row must contain: Account Number, Tran Currency Code, Sol ID, Part Tran Type, Transaction Amount, Transaction Particular, Value Date.

Excel Format

  • Row 1 must contain headers.
  • Headers: Account Number, Tran Currency Code, Sol ID, Part Tran Type, Transaction Amount, Transaction Particular, Value Date.
  • Data starts from row 2.
  • Header labels are case-insensitive.
  • Account Number such as 100110020034025.00 is converted to 100110020034025.
  • Value Date is written in the 10-character Finacle field.

TTUM Fixed-Length Layout

  • foracid: Position 1 to 16, length 16
  • tran_crncy_code: Position 17 to 19, length 3
  • sol_id: Position 20 to 27, length 8
  • part_tran_type: Position 28, length 1
  • tran_amt: Position 29 to 45, length 17
  • tran_particular: Position 46 to 75, length 30
  • rpt_code through rate: Position 76 to 178, 103 blank spaces
  • value_date: Position 179 to 188, length 10
  • gl_date: Position 189 to 198, 10 blank spaces
