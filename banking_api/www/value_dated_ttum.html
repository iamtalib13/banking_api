Finacle

Upload Excel and generate fixed-length Finacle TTUM lines with value dates.

No file chosen
Supported: .xlsx, .xls, .xlsb, .csv, .ods
Required headers: Account Number Tran Currency Code Sol ID Part Tran Type Transaction Amount Transaction Particular Value Date
All rows will be written into a single TTUM file inside a ZIP.

Excel Format

  • Row 1 must contain headers.
  • Headers: Account Number, Tran Currency Code, Sol ID, Part Tran Type, Transaction Amount, Transaction Particular, Value Date.
  • Data starts from row 2.
  • Header labels are case-insensitive.
  • Account Number such as 100110020034025.00 is converted to 100110020034025.
  • Value Date is written in the 10-character Finacle field.

TTUM Fixed-Length Layout

  • foracid: 1–16 (16 chars)
  • tran_crncy_code: 17–19 (3 chars)
  • sol_id: 20–27 (8 chars)
  • part_tran_type: 28 (1 char)
  • tran_amt: 29–45 (17 chars)
  • tran_particular: 46–75 (30 chars)
  • rpt_code–rate: 76–178 (103 blanks)
  • value_date: 179–188 (10 chars)
  • gl_date: 189–198 (10 blanks)
